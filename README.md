# Come Back to Magangué

Aplicación web turística bilingüe sobre Magangué, Bolívar. Se desarrollará como un sitio estático con HTML, CSS y JavaScript y se publicará en GitHub Pages.

## Estructura

- `index.html`: inicio de la aplicación.
- `assets/images/`: fotografías e ilustraciones con sus créditos documentados.
- `assets/icons/`: iconos propios o autorizados.
- `assets/icons/magangue-net-wordmark-transparent.png`: wordmark principal transparente para el encabezado; los archivos `magangue-net-logo.*` conservan el símbolo independiente.
- `pages/`: secciones y subsecciones independientes.
- `styles.css`: estilos responsive y paleta del proyecto.
- `script.js`: idioma, navegación e interacciones de cliente.
- `DESIGN_GUIDELINES.md`: roles de color, accesibilidad y patrones de interfaz.

No se utilizarán backend, Node.js, npm ni Vite.

## Language convention

Source code identifiers, filenames, comments, CSS custom properties, and technical documentation are written in English. Visitor-facing content is provided in both Spanish and English through a visible language selector. Spanish is always the initial language. The visitor can explicitly select `Español` or `English`; browser-language detection will not override the Spanish default.
